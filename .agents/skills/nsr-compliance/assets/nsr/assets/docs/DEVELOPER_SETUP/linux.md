# DEVELOPER_SETUP — Linux

- Debian/Ubuntu: `sudo apt install -y git bash python3 nodejs npm`
- Fedora: `sudo dnf install -y git bash python3 nodejs`
- SSH keys at `~/.ssh/`; `ssh-agent` for keys.
- Docker: add user to `docker` group if used.

## Gotchas
- Forward slashes; LF endings.
