# Tech-Stack Rules — __PROJECT__

1. **One primary stack per feature** — see `TECH_STACK.md` mapping; no undocumented second stacks.
2. **Pin versions** — recorded in `TECH_STACK.md`; no floating/latest in production.
3. **No new stack without registration** — update `TECH_STACK.md` + `FEATURES.md` first.
4. **Cross-platform** — stacks run on Mac/Linux/Windows or are containerized with pinned images.
5. **License & cost vetting** — before adopting a new stack.
6. **Consistency over novelty** — prefer the existing stack for a category.
