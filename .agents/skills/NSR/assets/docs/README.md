# docs/

Deep-dive technical documentation — the granular layer. `AGENTS.md`, `STRUCTURE.md`, and other root files link here; detail never lives at the root.

## What Goes Here

- `features/` — Per-feature deep-dive specs.
- `BEST_PRACTICES/` — Engineering standards (api, frontend, ...).
- `CI_CD/` — Pipeline configs + `deployment/` (envs, clients, tenants, deploy.sh).
- `DEVELOPER_SETUP/` — Per-developer core setup (consolidated + developers/).
- `HOSTING/` — Per-hosting core info (never break production).
- `RUNBOOK/` — Operational procedures & incident recovery.
- `research/` — Research sources (background, not operational).
- Practice documents (used operationally):
  - `working-with-agents.md` — how to work with agents.
  - `project-skills.md` — every skill a project must ship.

## Rules

- Fill per-project detail into these templates when adopting NSR.
- Practice docs are authoritative with `WayOfNorthstarRules.md` and `AGENTS.md`.
