# memory/ — Snotra's curated notes, not its memory

The distinction is plan 129 §21, and it is load-bearing:

- **The well holds the episodes.** Every meeting, every fault, every finding is an episode in
  `$YMIR_HOME/hodd/memory/well/episodes.jsonl`, written through `bin/records/mimir.sh observe` with the tag
  `domain:snotra`, recallable by meaning. That is the memory: append-only, shared, and it never shrinks (Rule 20).
- **This shelf holds the digest.** The curated few lines a keeper distils — what a meeting told us that we must not
  have to relearn. Small on purpose, pruned on purpose, and every line cites the episode or the file it came from.

A keeper whose only memory is a notebook has no memory; a keeper whose only memory is the well has no judgement.
Both, or neither is honest.

## The rules for a note here

- Date it. A note without a date cannot be weighed.
- Cite what it came from — a meeting slug, a fix note, an episode.
- Append; do not rewrite (Rule 06). A note that turned out wrong gets a dated correction beneath it, not an edit.
- Never paste a record, a transcript, a participant's address or a secret: this tree is public (Rule 04).

## The namespace

`domain:snotra` — declared in [`../domain.yaml`](../domain.yaml) so the register, the well and this shelf agree.
