# Domains — the Greinar

The eight fields of knowledge (Rule 01). Each is a **Grein**; together, **the
Greinar**. A domain is a field of knowledge, named for the figure whose craft it
is — never a company and never a workspace.

| Domain | id | Covers |
|---|---|---|
| Ymir Labs | `ymirlabs` | the system itself — agents knowledgeable about Ymir |
| Brokk Forge | `brokkforge` | engineering & build tooling |
| Runestone Labs | `runestone` | records & compliance |
| Muninn Labs | `muninn` | memory & knowledge |
| Dvalin | `dvalin` | crafted tools |
| Utgard Studios | `utgard` | creative |
| Askr | `askr` | human-centered products |
| Mannheim | `mannheim` | holding — allocated when a venture claims it |

The **house** (company) is `companies/wayof/` — WayOf. Domains are *not* companies;
the house owns projects, projects span domains. See `RULES/01-domains.md` and
`RULES/03-houses.md`.
