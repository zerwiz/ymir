# Way-Of — Workspace (Company Tenant)

Scoped operational memory for the way-of company realm.

- `company/` — Way-Of brand identity, mission, offers, strategy
- `marketing/` — copy, social calendars, campaigns, analytics
- `development/` — product specs, active repos (WOMONO, WOW, OPT), architectural docs
- `life/` — company-side scheduling
- `memory/daily/` — auto-generated daily logs `YYYY-MM-DD.md`
- `memory/entity_graph/` — key entity relationship notes
