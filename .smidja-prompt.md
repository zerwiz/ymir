# The Smíðja loads no team and answers every empty silently

Fix three faults, in one change, in this worktree.

## 1 · An empty answer must name its cause
`apps/smidja-factory/apps/visualizer/server/index.ts` answers `[]` for `/api/rosters` and `/api/models`
and `404` for `/api/memory` and `/api/chat`. An empty that does not say why is indistinguishable from an
empty house. Every endpoint that returns nothing must return a `cause` string naming the missing input
and the path it looked at (e.g. `no roster.yaml at /home/heimdall/Documents/ymirhome; the teams live in
config/agents.yaml`).

## 2 · A repo is never derived from a DB path
`server/roster-api.ts:34` calls `repoRoot(dbPath)` and hands the result to `roster_resolve.py`. The DB
lives in the HOME by design (`bin/desktop/smidja-board.sh` says so), so the resolver is pointed at a tree
with no roster. Introduce `SMIDJA_REPO_ROOT` (default: the checkout) as the only source of the repo root,
and stop deriving it from the database path.

## 3 · One team source, with a stated fallback
`server/roster_resolve.py` reads `roster.yaml`, which does not exist anywhere on this machine. When it is
absent, fall back to `config/agents.yaml` (the fleet's roster: figure → model, 23 figures in
`.agents/agents/`) and say which source was used in the payload (`source:`). The picker must show the
real team, not an empty list.

## Rules
- No silent empty anywhere: if it returns nothing, it says why.
