# 0.2.1 — the package is found by the words coders search with

**Date:** 2026-11-24 · **Component:** release

The operator asked *"what keywords should we have so most coders find us on npm?"* and decided the change belongs in the
next release, after every open PR is merged (plan 369 item 14).

- **`version`** goes from 0.2.0 to 0.2.1.
- **`keywords`:**
  - **Added:** the terms coders search for, such as ai-agent, coding-agent, multi-agent, claude-code, codex, opencode,
    cursor, ollama, mcp-server, model-context-protocol, git-worktree, sandbox, local-llm and devtools.
  - **Dropped:** the house names nobody searches for: brokk, eindri, fleet, omarchy and wsl.
- **`homepage`** points to https://ymir.zerwiz.org/how-to/, not the GitHub repository.
- **`description`** opens with the plain words, then keeps the old description in full after them.
