## agents · unversioned · 2026-09-22 — the errand loop, real (eindri-dispatch + eindri-arm)

### Why
The handoff machinery existed but was used by no one (0 briefs · 0 task
records · no backlog, probed). The Allfather's law: every Eindri carries its
own planning document, is armed until the work is handed off to Brokk, can
talk to Brokk (ask/answer/steer), and is never dispatched naked.

### What
- `bin/eindri-dispatch.sh` (new) — ONE command per errand: `new` (waves gate →
  brief via erindi-brief with the mission filled → data/<id>/plan.md, the
  errand's OWN planning document: mission · done-means · seat card ·
  environment · laws · channels · expected close · history · citations →
  state/<id>.meta → backlog row under flock → arm → spawn) · `close`
  (NO self-verdict — moves to review; the verdict is Brokk/Forseti's) ·
  `review` (the handoff ack) · `steer` (Brokk → inbox) · `questions`/`answer`
  (the worker's channel) · `status` (the ledger + arm beats).
  **The handoff minimum is enforced**: a dispatch without mission, done-means,
  mode, or seat is refused.
- `bin/eindri-arm.sh` (new) — the Eindri's OWN arm: claims the task, beats
  every cycle, acks steers, notifies answers, and on worker-done fires the
  close hook then **HOLDS until the review verdict exists** (Brokk received
  the work) — never retires armed work; TTL exit without handoff escalates.

### Files
- `bin/eindri-dispatch.sh` · `bin/eindri-arm.sh`

### Proof (functional e2e, 2026-09-22)
new → plan.md (4 sections) → question → Brokk sees/answers → steer acked →
worker done → **ARM HOLDS** → review pass → **ARM RETIRES** → backlog
accepted. The minimum gate refuses naked dispatches (verified 3×).
