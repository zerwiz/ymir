# A launcher may point at a worktree — never at a stale duplicate

**When:** 2026-10-23 · **Component:** agents · **Severity:** high

## What was wrong

The four desktop icons hardcoded one node path:
`~/.local/share/mise/installs/node/26.8.1/.../@zerwiz/ymir`. That copy was at
**0.1.52**, while the live global install was **0.1.53**. A click therefore ran a
build that predated the GPU-fence guard (`bin/graphics-lib.sh`, P7), and on this
hybrid Intel + NVIDIA machine under Wayland the Electron **GPU process aborted in
Mesa**:

```
Signal 6 (ABRT) si_code SI_TKILL
raise -> abort -> libgallium -> dri_create_fence_fd -> libEGL_mesa -> EGL_CreateSyncKHR
```

Three GPU processes died within twenty seconds, one per app. Every check said
"up": the parent Electron process lives on after its GPU process aborts, so
`electron.sh status` reported a healthy app that could not draw.

## What changed

- **`bin/desktop/desktop-verify.sh` gains a launcher check** — but a careful one:
  it compares the **version** named by the installed `.desktop` Exec with the live
  global install. A launcher that resolves at run time (a wrapper calling
  `npm root -g`) is always fine; a launcher pointing into a worktree is fine when
  the versions agree; a launcher pointing at an **older duplicate** fails, naming
  both paths and versions.
- **Gróa runs it** as step 6 of her daily wake, and reports `APPS: ok|FAIL: …`.
  An install that cannot open its own apps is no longer a silent pass.

## Why version, not path

Equality against one root would fail every worktree and teach people to ignore
the check. What matters is that the icon does not run an **older** copy than the
live install — a stale path is the fault; a different path is not.

## Proof

`desktop-verify.sh` on this host now reports `launcher matches the live install
(v0.1.53)` for all four surfaces, and fails loudly when pointed at 0.1.52.
With `--disable-gpu --disable-gpu-compositing` (which the live build passes on
this machine) `coredumpctl list --since` shows **zero** electron entries.
