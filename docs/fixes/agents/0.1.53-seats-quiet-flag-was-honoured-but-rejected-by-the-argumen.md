# `seat.sh --quiet` was honoured but rejected by its own argument parser

**When:** 2026-10-23 · **Component:** agents · **Severity:** low

## What was wrong

Gróa's seating script reads `--quiet` at the top and suppresses the proving check,
but the option parser below it did not know the flag:

```
unknown option: --quiet
```

So the update path — `groa-update.sh` re-seats her with `--quiet` — could not use
it, and every update would have run a full read-only check (up to 900s) after
already updating.

## What changed

`seat.sh` now accepts `--quiet` in the parser (`--quiet) QUIET=1; shift ;;`) as well
as reading it at the top.

## Proof

`bash -n bin/agents/groa-agent/seat.sh`; the flag is listed by the parser and the
proving check stays suppressed on the update path.

## Note

A flag read in one place and rejected in another is the sort of thing that only
shows up when the second caller exists — which is exactly what the update wiring
added.
