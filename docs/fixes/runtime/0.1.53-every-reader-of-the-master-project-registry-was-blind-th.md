## runtime · 0.1.53 · 2026-10-11 — every reader of the master project registry was blind: the hoard library was sourced from a path that does not exist

### Why
bin/skuld/registry-lib.sh sourced "$d/hoard-lib.sh" — the SIBLING path, bin/skuld/hoard-lib.sh, which does not exist. The library lives at bin/vault/hoard-lib.sh, and the shellcheck directive in the very same block named it correctly, so this was a typo with a consequence: _registry_load_hoard never set REGISTRY_LIB_HOARD_LOADED, hoard_root was never available, and registry_projects_file fell through to its last resort, bin/registry/projects.yaml. Every consumer — bin/agents/project-git.sh and everything downstream (mjollnir, yggdrasil, github-deploy) — reported 'registry not found: bin/registry/projects.yaml' and refused, until PROJECTS_YAML was exported in the environment. Found on 2026-10-10 while registering the chatcollab project, which could not be resolved afterwards: the entry was in the canonical home and invisible to the reader.
