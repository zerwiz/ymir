## runtime · 0.1.57 · 2026-09-30 — the contract said the A2A backbone was unbuilt; it was answering on `:8301`

### Why
Planning **many Ymir installs** (plan 61) meant asking what the mesh actually is. Measured on
zerwizserver before writing a line of it:

```
$ curl -s http://127.0.0.1:8301/.well-known/agent-card.json
{"name":"heart-zerwizserver",
 "description":"The record heart + the forge: gate, well, mill, served-MCP. The A2A node of the federation.",
 "url":"http://zerwizserver.<tailnet>.ts.net:8301/",
 "capabilities":{"streaming":true,…},
 "skills":[{"id":"well-recall","name":"well-recall","description":"Recall from the well"}]}
```

**The native backbone is built and running** — and both documents that say otherwise were wrong:

- `AGENTS.md:256` — *"the native backbone is **planned, not built** … Today an external `a2abridge`
  daemon … is what runs"*
- `docs/Architecture.md` (A.2) — *".agents/bus/ is a stub and the native Ratatoskr backbone is
  planned, not built"*

The second half of the claim was also subtly wrong: an `a2abridge` **does** run, but it is
**seat-side** (this seat, `:7777`) — the adapter a harness talks to — and **no `a2abridge` binary
exists on the server at all**. The thing answering on the server's `:8301` is Ymir's own node,
built from the shared contract in `packages/contracts` that 0.1.53 shipped.

Only `.agents/bus/` being a stub was true, and it still is.

**Why this mattered beyond tidiness:** a false "not built" in the always-loaded contract does not
merely mislead — it invites the next reader to **build what already stands**, and hides the fact
that the real gap is somewhere else entirely (a *directory* of installs and per-pair grants, which
is plan 61's subject).

### Fix
Both entries corrected **in place, as dated corrections that cite the old claim** — the append-only
law's shape, not a silent rewrite. Each now states: the backbone stands and answers, with the door
(`zerwizserver:8301`), the card path, the measured skills and `streaming: true`; that `a2abridge`
is seat-side; that `.agents/bus/` is still a stub; and that the missing thing is the directory of
many installs, named as plan **61** in the canonical ledger.
