## runtime · 0.1.85 · 2026-10-02 — the design studio is a CONTAINER — and three stdio MCP children outlived their sessions

### Files
- `bin/opendesign.sh`

## What was actually running, and the belief I had to drop

> *"stop open design"* … *"maestro are not open design. make stop and start script for open
> design"*

**Maestro is the video forge (`:7860`) and is untouched.** OpenDesign is the design studio
(``:7456"`), and it is a **CONTAINER**:

```
$ docker ps -a | grep -i design
open-design   od:local   Up 11 hours (healthy)
```

**My first draft of this door was written from a wrong belief** — that the studio was a process
whose name I could match, so `stop` refused: *"it is a separate process, and this door will not
kill an unnamed one."* The refusal was honest and the belief was wrong. What the evidence said:

```
ss -ltnp          → LISTEN, no owner
/proc/*/fd scan   → nothing
lsof -nP -i :7456 → nothing
fuser -v          → nothing
docker ps         → open-design, od:local
```

A socket with no owner in `/proc` is not a mystery: **it is a process in another namespace.** The
door now speaks the truth — container + the stdio children — and it reports rather than pretends
when something else holds the port.

## The other half: three MCP children outlived their sessions

`open-design-mcp` is a **stdio** server: one per session that loaded the hnoss extension, and
nothing calls a stdio server after the session ends. Three were up for **10+ hours each**
(71–72 MB). That is the same failure class as everything else tonight — a process that exists, is
never asked for again, and is never reaped. `stop` sweeps them, and `status` counts them.

## Proved, both directions

```
start  →  "studio answering at http://127.0.0.1:7456/"
status →  "studio :7456 up · container running · stdio MCP children 0"
stop   →  ":7456 is silent — the design plane is down"
          "Maestro (the video forge, :7860) was NOT touched."
status →  "studio :7456 down · container stopped · stdio MCP children 0"
```

And it ends the way he said it should: **down**. The door is there for the next time he wants it.
