and the reader sees zero. Both append sites in `bin/seat/seat-wire.sh` now terminate the line.

`tail -c 100 ~/Documents/ymirhome/state/.wake-queue | od -c` ends `\  n  \n` and `wc -l` reports **1** where it reported **0**
before the change. His drain presented the line on the first pass after it landed.

**His caveat stands:** his running drain is still the unrepaired build (PR #512 open), so the trailing newline is what makes it work today; the
unterminated case is only safe once #512 merges. **Write `%s\n`, keep both fixes.**
