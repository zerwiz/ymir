## runtime · 0.1.0 · 2026-10-18 — Sól — one clock door, correct across daylight-saving

### Why
Every agent was reaching for date with different flags, zones and formats; and subtracting two zone-aware datetimes in Python is WALL-clock arithmetic that silently drops the skipped DST hour (measured: 01:00 to 04:00 on 2026-03-29 is 2h elapsed but 3h wall). bin/time/sol.sh is the one door: now/iso/utc/epoch/stamp/tz/add/diff/context/check, deterministic via --at and --tz, DST-correct because arithmetic is on instants and a nonexistent wall time is normalised. Wired into the Saga session digest so every session and log line wears the same instant. Tests .agents/tests/sol-clock.test.sh 21/21.
