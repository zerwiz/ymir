## runtime · 0.1.1 · 2026-10-18 — The clock's check reads the sync state even where 'timedatectl show' refuses

### Why
The warden's report said ntp_synchronized=unknown on a machine that is plainly synced: 'timedatectl show -p NTPSynchronized' can fail without a seat in the logind session. sol.sh check now falls back to the human form and parses 'System clock synchronized: yes'. A clock door that answers unknown where the answer is knowable is a door nobody trusts.
