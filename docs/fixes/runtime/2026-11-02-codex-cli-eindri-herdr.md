# Codex CLI can wear an Eindri seat

The runtime rejected Codex as unverified, its shell builder had no Codex launch shape, and the direct start door dropped the selected kind. Codex now has an explicit verified adapter, native model/default handling independent of Pi, quoted prompt delivery, and kind propagation to Herdr. Offline tests cover model separation and prompt bytes including shell metacharacters. Live Herdr launch must be verified from a managed pane; this change was prepared outside Herdr and does not claim that live proof.
