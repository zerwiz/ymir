## runtime · 0.1.54 · 2026-09-29 — a lock wait with no bound, and a seat with no scratch

### Why
Two isolation gaps, both found while triaging the bash crash storm.

1. **`fm_lock_acquire_wait()` was unbounded** — `while ! fm_lock_try_acquire; do sleep 0.1; done`,
   no timeout, no attempt cap. A publish lock that is never freed (a stale owner, or the
   `lock-changed` fixture case, which changes one on purpose) wedged the worker at 10 Hz
   forever. `bin/backend/fm-startup-network.sh:await_delivery` calls it twice, so a wedged delivery
   blocks the deferred stage that exists precisely to keep work off the blocking path.
2. **Two errands shared one scratch directory.** A worktree isolates the CODE and a seat
   state dir isolates the STATE, but the launch env exported `TMPDIR` not at all — so
   opencode, `mktemp -d` and every headless Chrome `--user-data-dir` converged on
   `/tmp/opencode`: **282 MB** of browser profiles and two errands' fixture files in one
   shared namespace, with no reap. Parallel errands sharing scratch by accident is the
   collision the isolation law exists to prevent.

### Fix
- The wait is **bounded**: `fm_lock_acquire_wait <lockdir> [max-seconds]`, default
  `FM_LOCK_WAIT_MAX_SECS=30`, counted in **integer tenths**. It gives up with a named reason
  (`unavailable, not free`) and returns non-zero so the caller can degrade.
  Integer arithmetic is load-bearing: the first attempt computed the step through `awk` with
  the value interpolated into the awk *program*, which the shell expanded first — under
  `set -u` that is an unbound-variable error on **every** iteration. Integer tenths have no
  quoting trap and no fork.
- `src/ymir_runtime/backend.py` exports **`TMPDIR=<seat-state>/tmp`** (mode 0700) beside the
  two exports that were already there, so each seat's scratch is its own and dies with the seat.

### Verified
- Held lock with a live owner: `fm_lock_acquire_wait` returns 1 after exactly its bound and
  prints the reason — no stray errors, no spin.
- `_pane_cmd('opencode --prompt x', '/tmp/seat-probe/state')` →
  `BROKK_MACHINE_STATE_DIR=… BROKK_STATE_OVERRIDE=… TMPDIR='/tmp/seat-probe/state/tmp' opencode --prompt x`,
  and the scratch dir is created.
- `python3 -m unittest discover -s ymir_runtime/tests` → 297 tests, OK (42 skipped).
