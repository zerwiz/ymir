## sessrumnir · 0.1.0 · 2026-10-18 — Opening a file on the right display — the opener understands screens and dialects

### Why
Placing a window on a named monitor was hand-done per session, and Hyprland 0.56 with an Omarchy Lua config rejects classic dispatchers (movewindow mon:...) with a Lua syntax error that looks like a broken desktop. display-lib.sh now probes the dialect and resolves monitor ROLES (reading = the largest, code = the focused); open-on.sh opens one window per file, places it by role, reuses an open window, and skips placement cleanly off Hyprland. /edit and ctrl+shift+e now route GUI editors through it.
