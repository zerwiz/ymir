## sessrumnir · 0.1.53 · 2026-09-29 — the weave lost a brace and the hearth could not compile

### Why
`apps/sessrumnir` did not build, so `prepack` failed and **no npm release of any kind
could ship** — the platform tarball builds every app first.

The fault arrived in the merge `fc3fc43` (*merge yggdrasil/ember-hearth into the
integration weave*). It wedged the branch's `ResizeObserver` host-observation block into
`main`'s effect, and the weave left one brace behind:

```tsx
    return () => {
      cancelAnimationFrame(raf)
      window.removeEventListener('resize', onResize)
      if (ro) ro.disconnect()
    }
    }          ← closes the effect a second time
  }, [])       ← nothing left to attach to
```

esbuild: `ember-background.tsx:135:2: ERROR: Expected ")" but found "}"`.

The behaviour the branch wanted is intact — the observer re-seeds the embers when the
host's dimensions actually change, which is what stops the canvas being one pixel wide
in a hidden pane. Only the stray brace was wrong.

### Fix
One line removed (the second `}` after the cleanup `return`). No behaviour change, no
other line touched.

### Verified
- `cd apps/sessrumnir && npm run build` → clean (was a hard esbuild failure).
- `bin/seat/sessrumnir/app-build.sh` → `{"built":3,"skipped":0,"failed":0}`; `npm pack --dry-run` at the
  root then packs the whole platform.
