## sessrumnir · 0.2.0 · 2026-10-18 — The bin/ tree: no code in an application's folder, and one editor door

### Why
Rule 22: an application lives in apps/ and bin/ holds function-named machine tools. bin/seat/sessrumnir/ — a directory named after an APPLICATION — held seven misfiled files (app-build, app-lib, desktop-place, desktop-verify, editor-place, sessrumnir-ensure, sessrumnir-sync) plus a new display tool; all moved to bin/desktop/ and the directory is gone. The editor door is ONE: bin/engine/ymir-edit.sh now places by ROLE (reading = the largest display, code = the focused one) over bin/desktop/display-lib.sh, which PROBES the dispatcher dialect — the old classic comma-form move failed silently on Hyprland 0.56. bin/desktop/sessrumnir.sh renamed sessrumnir-launch.sh. New ward bin/gates/guards/app-folder-guard.sh, registered in guards.sh.
