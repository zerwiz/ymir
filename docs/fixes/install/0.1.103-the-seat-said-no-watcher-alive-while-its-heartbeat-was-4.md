# 0.1.103 — the seat said "no watcher alive" while its heartbeat was 4 seconds old

> The install check, run on a seat that was in fact fine.

## What it said, and what was true

```
watch-loaded    ok    heartbeat 4s old
watch-running   MISSING  no watcher process is alive
verdict         NOT WHOLE  1
```

Both rows were about the same watch. One measured it; the other asserted a **name**.

## The name was a guess, and it matched nothing that exists

```bash
pgrep -f "syn-watch|gna-watch|branch-supervision"
```

The watcher on this host actually runs as:

```
pid 1206  python -m ymir_runtime watch run
```

Not one of those three patterns matches it. So the seat reported a dead watch while the heartbeat
proved it was alive — **and this is the second time the same fix has been needed on the same row**:
first it demanded `.pi-gna-watch-loaded`, a marker nothing in the house writes; now, once that was
replaced with a real liveness measurement, it demanded process *names* that no process uses.

## The pattern now uses names MEASURED here

```
ymir_runtime watch · ymir_runtime supervise · syn-watch-arm · syn-watch.sh
gna-watch · branch-supervision · watch-drain
```

And the pass line no longer interpolates `${WATCHER_PIDS}` when that is unset, which under
`set -u` was throwing `WATCHER_PIDS: unbound variable` the moment the pgrep branch was taken.

**Verified, not assumed:** `verify-seat.sh` now exits **0** and reports `WHOLE, 0` with
`watch-running ok — pid(s) alive: 1206`.

## The pattern across the whole week, one more time

| | the check asserted | the truth was |
|---|---|---|
| 0.1.95 | files copied | files that **parse** |
| 0.1.98 | tools declared | tools that **answer** |
| 0.1.99 | a name prefix (`fm-`) | whether anything **uses** the file |
| 0.1.101 | no `handler:` anywhere | `handler:` inside a **registerTool** |
| 0.1.102 | a resolved path | a path derived from **where the code runs** |
| **0.1.103** | a marker file, then process **names** | a **fresh heartbeat**, then a real pid |

Every one of these was a check written from what *ought* to be true, rather than from what
*is*. And in every one, the check was green (or red) for a reason unrelated to the thing it
claimed to measure.

> **A check must be written from the thing, and the name must be measured — never assumed.**

The install is now complete and the seat is whole: 18/18 extensions deployed and parsing,
watch alive on both counts, helm held by a live pid, vault resolved.
