# Chapter XXXVII said YmirCode's Rust core was built; it is in design

The first commit of chapter XXXVII (`docs/lore.md`) marked Rust as **built** ("YmirCode's core is Rust") and Elixir
and Ash as named only. YmirCode's own `README.md` gives its status as **design**: the specification and plans are
written, and the only code is a terminal UI prototype.

Corrected in the same pull request, before merge: Rust for the core and a separate Elixir/OTP control plane for hosted
work are both **decided** (YmirCode ADR 0012, 2026-11-23); the core is in design; the plane is not started; "Ash" is
the house's Elixir habit, not a decision of that plan; the desktop is egui by ADR 0010.
