## forge · 1.1.0 · 2026-11-06 — the factory inside the box, a budget that runs out, and the lanes that compare

### What

Plan 209's P2–P4, and the four mechanisms the full transcript added (§11.1). The floor from 1.0.0 (the box, the door)
did not change shape; it grew the things that make it usable for real work.

- **P2 — the factory inside.** `utgard box factory <name>` copies Smíðja into the box (`smidja_modules`,
  `smidja_smidja_config`, the chains), and `utgard box run <name> -- <command>` runs one command there. The box image
  now bakes `pydantic · python-dotenv · pyyaml · rich`: a box sealed to one road cannot reach PyPI, and a factory that
  installs itself would work on the host and fail in the box.
- **P3 — lanes.** `bin/forge/utgard-lane.sh`: `new · run · board · list · rm`. One brief, N boxes that differ in one
  declared way, a **rail lease** (`flock`) so the lanes queue on the single model slot instead of thrashing the swap, and
  a board of `label · model · where · wall · last line`.
- **P4 — the estate.** `box estate` reads every live box with both doors and who answers; `box enter --all` opens one
  pane per live box in a single gesture, and says so plainly when herdr is not available rather than pretending.

**§11.1's four, all present:**

1. **A budget is part of the credential** (not a nicety): `--budget N`; the door counts what it serves, refuses past the
   cap with the number it stopped at, and `box status` shows `spent/budget`. `box revoke <name>` takes the key back at
   once, and `stop`/`rm` do it too.
2. **The estate is entered all at once** — `enter --all`, one pane each.
3. **Two addresses per box** — the application it made, and the factory that made it (default 4601). `box url` names
   both, and each says whether it answers.
4. **The lane axis includes where the model lives** — `label=model@local` or `@tailnet`; a tailnet lane reads
   `UTGARD_LANE_TAILNET_TARGET` and refuses with the reason when it is unset, because an address is never written into a
   script.

**Two faults found by running it, both silent by nature:**

- **A fresh Docker volume is root-owned and the door runs unprivileged** — so every charge failed with `OSError` swallowed
  by the door's own error handling, and the budget refused at the cap while reporting `0/N`. The spend is now handed to
  `agent:agent` **before every door start**, not only at volume creation: a volume left root-owned by an older run would
  otherwise keep the same silent hole. A budget that cannot record what it served is not a budget.
- **Two boxes made in the same second took the same loopback port.** A port was considered free if nothing listened on
  it, but a box that has not started its server yet listens on nothing. Free now means nothing listens **and** no live
  box claims it by label.

**Also corrected:** `box rm` now reclaims the door's state volume. A spend that outlived its lane would cap the next one
for a run it never made.

### Verified

- `bash tests/test_utgard_box.sh` — **41 pass, 0 fail, 0 skip** against a live engine with a stub upstream. New in this
  pass: the factory seats and its dependencies import inside a sealed box; a budgeted box is served before its cap and
  refused after it *with the count*; `status` shows what the door spent; `url` names both doors; `estate` reads both;
  `enter --all` covers the estate; `revoke` removes the door.
- `bash tests/test_utgard_lane.sh` — **18 pass, 0 fail, 0 skip**: a lane with no brief or no `--lane` is refused; a
  malformed spec is refused; a tailnet lane with no target is refused; three boxes carry the lane's labels and its declared
  axis; the brief reaches every lane as a copy; the run holds a real lease file; all lanes run; the board names what it
  compares, carries each lane's last line, marks nothing failed that succeeded, has a row per lane, and ends in the
  operator's pick; `rm` takes every box and every door.
- Both suites skip cleanly (exit 0, with the reason and the fix) when there is no engine, no daemon, or no image.
- The box image rebuilds in ~1m20s with the factory's dependencies baked in.

### Owed, unchanged

The one firewall rule `box probe` prints. Until it exists, a box reaches nothing but its door and the door reaches
nothing but a closed port; the other laws hold either way.
