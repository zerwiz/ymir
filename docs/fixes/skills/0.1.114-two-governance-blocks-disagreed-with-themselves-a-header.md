# 0.1.114 — two governance blocks disagreed with themselves

Both were pre-existing from earlier merges, not caused by the `bin/` move. Found by
`compliance-check`, and both are the same shape as the night's lesson: **a block whose header
disagrees with its own body.**

## 1 · `AGENTS.md` — two TOON header counts were wrong

```
AGENTS.md:130  governed[10] declares 10 rows but has 11
AGENTS.md:415  rules[6]   declares 6 rows but has 7
```

Both counts were **understated by one** — the rows were there, the headers were stale. Fixed to
`governed[11]` and `rules[7]`. The `rules` block gained `RULES/13-pi-extensions.md`; the `governed`
block gained a `tools/snotra/**` row. Nobody updated the numbers, so the contract that governs the
house disagreed with the house.

**TOON: 99 blocks valid** after the fix.

## 2 · The Galdr agent had drifted from the Galdr skill
