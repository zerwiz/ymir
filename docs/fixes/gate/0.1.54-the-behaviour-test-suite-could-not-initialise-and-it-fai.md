## gate · 0.1.54 · 2026-09-29 — the behaviour-test suite could not initialise, and it failed silently

### Why
Chasing a bash SIGSEGV storm led to a much older fault underneath it. **`.agents/tests/fm-startup-network.test.sh` cannot run at all**, and when it fails it says nothing useful:

```
.agents/tests/lib.sh: line 1: fm_test_cleanup: command not found
.start-nonblocking/root/bin/ps: No such file or directory     ← note the leading /
not ok - the detached worker never recorded itself
```

Every fixture path collapsed to `/<world>/…` because `TMP_ROOT` was empty, and `fm_test_cleanup`
was never defined — so the test's EXIT trap was calling a function that did not exist.

**Three faults, stacked:**

1. **`.agents/tests/lib.sh:41` derived `ROOT` one level short.** `ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"` — the lib lives at `.agents/tests/lib.sh`, so its parent is `.agents/`, and `$ROOT/bin/fm-wake-lib.sh` resolved to `.agents/bin/fm-wake-lib.sh`, which has never existed. `git log -S` puts that line in **`3c99ba0`, the repository's first commit**: the behaviour suite has been unable to initialise for as long as this repo has existed.
2. **It failed SILENTLY, because lib.sh is SOURCED.** On failure it did `return 1` out of a sourced file, so the caller carried on with a half-built harness — no `fm_test_cleanup`, no `TMP_ROOT`, and a wall of "No such file or directory" that names a fixture path rather than the cause. A sourced library that cannot initialise must speak, or exit.
3. **`bin/fm-test-run.sh` never exported `ROOT`.** It computed `ROOT` at line 120 for its own use and then invoked `bash "$script"` — so every `$ROOT`-dependent test got an empty value from its environment.

### Fix
- `lib.sh` resolves two levels up, and an **inherited `ROOT` wins** (the runner's is the real one).
- `lib.sh` prints the actual reason on failure — naming `ROOT` and the temp root — and says how to run the suite properly.
- `bin/fm-test-run.sh` exports `ROOT`.

### Verified
- `. .agents/tests/lib.sh` → `rc=0`, `fm_test_cleanup` is a function, `ROOT=$HOME_SEAT/ymir`, the pid identity resolves.
- `bin/fm-test-run.sh --per-script-timeout-secs 300 .agents/tests/fm-startup-network.test.sh`
  → `exit=0 · total=1 failed=0 · "all assertions passed"` (it had never run before this change).
