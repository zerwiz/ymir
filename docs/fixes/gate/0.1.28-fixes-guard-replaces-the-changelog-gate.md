## gate · 0.1.28 · 2026-09-18 — fixes-guard replaces the changelog gate

### Why
changelog-guard passed if a range merely touched CHANGELOG.md, and the hook folded fragments mid-push. The new gate only reads: a push must carry a note under docs/fixes/<component>/. It refused its own first push, which is the proof it has teeth.
