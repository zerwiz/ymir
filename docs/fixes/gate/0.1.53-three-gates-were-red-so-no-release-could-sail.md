## gate · 0.1.53 · 2026-09-29 — three gates were red, so no release could sail

### Why
The Allfather said *push ymir to npm again*, and the tree could not have gone: the
compliance gate — which is `npm test` — failed three of sixteen wards, and `prepack`
could not build. Every one of the three was a real defect, not a stale expectation.

- **`config` (Rule 07) — a tracked file carried a seat's absolute paths, one of them
  wrong.** `.pi/mcp.json` was tracked and held
  `"$HOME_SEAT/hodd/memory/kaia.engram"` — the pre-vault layout, missing
  `Documents/ymirhome` — plus the absolute `engram-mcp` path. The canonical Pi config
  `.pi/mcp-adapter.json` has been gitignored since commit `dcfb4f2` ("config: render
  machine config from examples instead of shipping absolute paths") precisely because a
  rendered list holds machine paths. The bare list was missed by that fix and would have
  shipped the author's home layout inside a **public** tarball.
- **`mocks` — an upstream comment tripped the ward.** `bin/fm-composer-lib.sh:484`
  carries its arity on the function line: `… [plain_content] [placeholder-position]
  [styled]`. The ward excludes pure comment lines but not a trailing comment, and
  `\bplaceholder\b` matched the hyphenated `[placeholder-position]`. The declared
  handling in the harness-integration asset (§12) is that the gate's scope is the
  runtime and the provenance is the record — so the note was **not** the mend; the
  comment was wrong about its own parameter, which is `placeholder_position`.
- **`assets` — a governed path moved without its owner.** Untracking the Pi configs is
  a change under `.pi/*`, whose owning asset is
  `assets/harness-integration/README.md`. The ward compares changed governed paths
  against the asset changed in the same change; the asset now records the rendered-vs-
  template contract for both Pi lists and for `*.bak-*` seat backups.

### Fix
- `.pi/mcp.json` untracked and gitignored, with `.pi/mcp.json.example` added carrying
  `__YMIR_HOME__` exactly like the adapter's template. `.pi/*.bak-*` ignored — a seat's
  own backups are never craft and never ship. Two tracked `.bak` files removed from the
  index.
- `bin/fm-composer-lib.sh:484` — `[placeholder-position]` → `[placeholder_position]`,
  which is the parameter's real name. No behaviour change.
- `assets/harness-integration/README.md` — the rendered/template contract recorded beside
  the harness table; Tyr mirrors the tree by symlink, so both copies are current.
- Root `package.json` and `package-lock.json` → **0.1.53** (npm's latest was 0.1.52).
  The lock was also stale against the manifest and picked up `@capacitor/ios` while it
  was regenerated.
