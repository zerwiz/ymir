## gate · 0.1.53 · 2026-09-29 — the typed-surface gate failed a checkout it had never installed

### Why
The release PR's CI went red on a gate, not on the release:

```
"contract","FAIL","packages/contracts/tsconfig.json"
  error TS2688: Cannot find type definition file for 'node'.
"a2a-server","FAIL","packages/a2a/ratatoskr/tsconfig.json"
  error TS2688: Cannot find type definition file for 'node'.
```

The packages are fine — `packages/contracts` type-checks clean on this seat. **The gate
broke its own stated rule.** `bin/contracts-check.sh` says so in its header:

> The tsc legs SKIP loudly when tsc (or Hlidskjalf's node_modules) is absent: CI
> checks out without an install, and a gate that cannot run must say so, never fail
> the push.

The Hlidskjalf leg implemented that with `modules_present`. **The `contract` and
`a2a-server` legs did not** — they ran `tsc --noEmit` whenever a `tsc` binary was
reachable, and on the CI runner one is (via the npx cache). So on a checkout that had
never been installed, tsc could not resolve `@types/node` (the test files import
`node:test` and `node:assert/strict`, so the types are genuinely needed) and the gate
reported a **type error in correct code**.

A gate that fails a correct tree is worse than no gate: it teaches authors to ignore it,
and it makes CI lie about the release.

### Fix
- `tsc_leg` now applies `modules_present` to **every** leg it runs, not just the UI one:
  no `node_modules` in the tree or up-tree → a loud `SKIP` naming the remedy
  (`run npm install to type-check <project>`), never a `FAIL`.
- `modules_present` is now defined **before** the first `tsc_leg` call. Bash resolves
  function names at call time, so a leg that asked earlier would have found no such
  command, taken the non-zero exit as "no modules", and skipped itself on every machine
  — including this seat, where the type-check is real and passing. The comment records
  that trap.

### Verified
- This seat (node_modules present): `contracts-check.sh` → `tests PASS (4 · a mismatched
  card is refused)`, `contract PASS`, `a2a-server PASS`, `hlidskjalf PASS`. The legs still
  run; nothing was silenced.
- A **cloned bare checkout** with no `node_modules` anywhere: all three legs `SKIP` loudly
  and the gate passes.
- The **exact CI case** — bare checkout *with* `tsc` on PATH: the two legs now report
  `SKIP … run npm install to type-check …` instead of `FAIL … TS2688`.
- `bash -n` clean; the behavioural proof (`node --test packages/contracts/test/`) still
  runs everywhere, because it needs no dependencies at all.
