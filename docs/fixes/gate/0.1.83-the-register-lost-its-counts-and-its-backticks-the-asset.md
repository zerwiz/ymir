## Three defects my own hand found, all in the register I built hours ago

1. **The register had lost its `capabilities[5]` headline.** A nested-heredoc edit while adding
   the engine section consumed the first fence, so the counts block never reached the output — and
   `ymir_hall` read it and printed `? ? ? ?`. It now emits the block by `printf` (no nested fence
   to break), and the register again carries the truth:

   ```
   capabilities[5]{surface,count}:
     "shell doors (bin/*.sh)",389   "runtime modules (src/ymir_runtime/*.py)",54
     "skills (.agents/skills/*)",29  "Pi extension tools",33      "generated","2026-10-02"
   ```

2. **Every table cell carried literal backticks** (`` \`a2abridge-ensure.sh\` ``) from the same
   surgery. Gone.

3. **The repo's own asset shelf has no index** — `.agents/assets/agents` holds 5 docs and no
   README, so `bin/gates/checks/home-index-check.sh` was pointed at the home only and missed it. It now walks
   `.agents/assets` too, and immediately reported it. `naming.md` and `registry.md` are **how an
   agent finds what a thing is called**; a shelf of five with no index is invisible by accident —
   **in our own tree, not only in the operator's.**

**The lesson, fourth time tonight: the generator is the artefact.** Every one of these lived in the
*writer*, not the reader, and a reader that cannot say "this is wrong" is what let them sit.
`--check` now catches a stale register, an unreadable header and a missing shelf index — but the
first reader of a malformed file is still a human or an agent, and both of mine trusted it.
