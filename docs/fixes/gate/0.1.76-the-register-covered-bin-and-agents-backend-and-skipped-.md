## A register that skips the engine is half a register

The capability register covered `bin/` (382 rows) and `.agents/backend/` — and **not
`src/ymir_runtime`**, which is the **engine**: 48 modules, the ones the House has actually been
moving INTO. A register that documents the rooms and ignores the engine is exactly the sort of
half-measure this whole plan exists to end.

**§1b now covers it**, and the columns are read, never asserted:

```
| module            | what it owns (its OWN docstring, first line) | tested | reachable from a door |
| backend.py        | where a seat's pane actually lives           | yes    | yes (bin/ imports)  |
| load.py           | load a hoard config WITH its schema          | yes    | yes                 |
| __main__.py       | the door face of the config layer            | yes    | yes                 |
```

All **48 modules**: every one carries a docstring saying what it owns, **every one is touched by a
test**, and **every one is reachable from a door** — which is the finding that matters: the engine
is *better looked after* than the shells around it. 432 rows now, and `--check` fails if the
register and the tree disagree.
