## Four things this cost, each real

**1 · The 0.1.111 bug, again, in the file that moved.** Nineteen doors resolved `ROOT` by
`dirname $0/..`, which from two levels down gives `bin/` — so `ci-verify` invoked
`bin/bin/gates/guards.sh` and reported ten gates FAIL that were fine. The marker-walk was
re-applied to every moved door.

**2 · My repoint script skipped the common case.** Its lookbehind `(?<![\w/-])` excluded a
preceding `/`, so **every `$ROOT/bin/…` reference survived broken** — 174 files. A regex that
guards against matching too much, without a test for what it must still match.

**3 · The index went blind again.** `inventory.sh` walked `bin/` root only and reported
**148 of 398** doors, calling it current. Both enumerators are now recursive.

**4 · The governed contract had to move with the code.** `AGENTS.md`'s governed block still named
`bin/ymir-install.sh`, `bin/mimir*.sh`, `bin/nornir-*` — and compliance **refused** until they were
repointed. That is the gate working exactly as designed: a move that does not update its own
contract is an incomplete change.
