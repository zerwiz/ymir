## gate · 0.1.58 · 2026-09-30 — two silent swallows let a tarball ship with no app surfaces

### Why
CI on #257 failed with a symptom three steps from its cause:

```
FAIL: app-boot: sessrumnir web surface not built
  (/tmp/npm-pretest-…/node_modules/@zerwiz/ymir/apps/sessrumnir/out/main/index.js)
```

**Two swallows stood between the fault and the report:**

1. **`bin/seat/sessrumnir/app-build.sh` discarded every build's output** (`npm run build >/dev/null 2>&1`) and
   then printed *"FAILED — see its output above"* — above nothing. The log that would have said
   *why* the surface did not build was thrown away one step before anyone asked.
2. **`bin/forge/npm/npm-pretest.sh` piped it through `tail`**: `"$ROOT/bin/seat/sessrumnir/app-build.sh" 2>&1 | tail -3 || say
   "WARN…"`. A pipeline's status is its **last** command's, so `tail` returned 0 and the `||` could
   never fire: **a failed build could not fail the gate.** The pretest went on to pack a tarball
   whose surfaces were never built, and named the missing file three steps later.

This is why the failure looked like a packaging fault and was not one — the tarball is fine; the
build that should have filled it was never allowed to speak.

### Fix
- `app-build.sh` writes each build's output to a named log and, on failure, **prints the log's
  path and its last 15 lines**. A build that fails silently is how a tarball ships empty.
- `npm-pretest.sh` runs `app-build.sh` with **no pipe**, into `$WORK/app-build.log`. Success tails
  it; **failure fails the pretest immediately**, with the log's tail attached, and never packs.

### Verified
- A **deliberately broken** build (`hlidskjalf`'s `build` set to `exit 7`) now reports
  `FAILED — build log: /tmp/app-build.N8xcXP.log` **with the log lines shown** — the exact case
  that was invisible before.
- The happy path still passes locally: `app-build.sh` → `{"built":4,"skipped":0,"failed":0}`.
- `bash -n` clean on both scripts; `bin/gates/guards.sh` PASS.

The heavy gate itself (`pr-pretest.sh`, a real 43 MB install) is **not** re-run here on purpose:
CI proves it in ~2 minutes, and running it in the foreground cost 22 minutes for the same answer.
