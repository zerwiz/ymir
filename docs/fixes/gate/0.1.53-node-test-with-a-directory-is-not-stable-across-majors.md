## gate · 0.1.53 · 2026-09-29 — `node --test` with a directory is not stable across majors

### Why
The gates workflow went red three times on the **same** leg, and the first two diagnoses
were wrong. This note is the third, and it is the one the evidence supports.

```
Error: Cannot find module '/…/packages/contracts/test'
    at Module._resolveFilename (node:internal/modules/cjs/loader:1164:15)
  code: 'MODULE_NOT_FOUND'
✖ packages/contracts/test (84ms)   ℹ tests 1  ℹ pass 0  ℹ fail 1
```

**`node --test <directory>` is not a stable contract across node majors.** On Node 24 the
argument is resolved as a **module entry point** and the runner dies before a single
assertion; on Node 26 the same argument is treated as a directory to search and the suite
passes. So the gate's verdict depended on which node the room happened to be — and because
every seat that a developer works on runs 26, the failure was **unreproducible locally**
while being reported as a fault in correct code.

For the record, the two earlier diagnoses and why they were wrong:
- *"the runner cannot strip TypeScript"* — wrong. Type stripping is on by default from
  Node 22.18/23.6; the error was `MODULE_NOT_FOUND` at module resolution, long before any
  type was involved.
- *"`@types/node` is missing, so type-check it"* — right about that leg, wrong about the
  run: the type-check legs now SKIP on an uninstalled checkout (the sibling note), and the
  **tests** leg is the one that broke.

### Fix
Pass the **files** and let the shell expand the glob — the one form that means the same
thing on every supported node:

```sh
node --test packages/contracts/test/*.test.ts     # was: node --test packages/contracts/test/
```

The identical latent fault in `packages/contracts/package.json`'s own `test` script
(`node --test test/`) is corrected in the same change, so `npm test` inside the package
cannot fail the same way.

### Verified — both rooms, the same suite
| Node | `pass` | `fail` |
|---|---|---|
| 24.21.0 (the pinned CI room) | 4 | 0 |
| 26.8.1 (this seat) | 4 | 0 |

And the whole gate under a **bare checkout** on Node 24 — the exact CI shape:
`tests PASS · contract SKIP · a2a-server SKIP · hlidskjalf SKIP` → `contracts-check: PASS`.

The gate now proves the same thing in every room, which is the only property a gate is
allowed to have.
