## gate · 0.3.0 · 2026-10-18 — Rule 25 — agnostic by construction, and the path ledger that enforces a move

### Why
The Allfather: 'we can't develop with one device in mind... we need to be agnostic.' The day gave the proof: the bin/ reorganisation moved the scheduled jobs to bin/time/ and the operator's own cron kept the old spellings for three weeks (on every seat), while the warden read Linux-only sources and the editor door was written against Hyprland 0.56. Rule 25 states it: three axes (device, hardware, OS); probe never assume; a clean skip is a pass; one core and thin layers; paths resolve, never hardcode; and A MOVE IS A MIGRATION. Enforced by .agents/paths-ledger.yaml + bin/gates/guards/path-ledger-guard.sh (no shipped file may reference a superseded path; history and a written waiver excepted; a hit that is a suffix of the new path is not a reference) and by .agents/migrations/0009-flat-bin-paths.sh, which heals an existing home's config and docs on its next update. Fixed on the way: the capability inventory, the shipped cron examples, the Nornir how-to that told a seat to write jobs at the moved path, three Galdr assets, and two historical lines that now carry the written waiver.
