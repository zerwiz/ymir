# 0.1.102 — the new gate failed in CI for the same reason it had passed here: assuming a machine

> The gate added an hour ago (`ext-smoke`) passed on this seat and failed on every CI run.

## What CI said

```
"ext-smoke","FAIL"
  ymirhome    LOAD FAILED  ENOENT: no such file or directory
  odrerer     LOAD FAILED  ENOENT: no such file or directory
  rules       LOAD FAILED  ENOENT: no such file or directory
  … 11 in all
```

## Why — and it is the same disease as 0.1.97

To satisfy the ward I replaced a hardcoded `/home/heimdall/ymir` with:

```js
process.env.YMIR_ROOT  ||  the first root recorded in ~/.pi/agent/extensions/.ymir-root
```

Both are **facts about a machine**. A CI runner has neither: no env, no vault, no pointer. So the
gate that had just replaced "this laptop's path" with "this seat's pointer" still assumed
**some** seat — and it happened to be this one. The ward was satisfied and the gate was still wrong,
which is worse than before: it now looked careful.

## The third door

```js
const checkout = fileURLToPath(new URL("..", import.meta.url));   // this file IS in the checkout
```

Resolution order, and the last one **cannot** be wrong:

1. `$YMIR_ROOT` — a machine with several roots, or a test that wants one
2. the recorded pointer — an installed seat
3. **the checkout this script lives in** — a bare `git clone`, which is exactly what CI is

## And a second thing worth naming

In CI, six tools still ran and **eleven extensions refused to load** — because several resolve the
root at module top-level and a checkout has no vault. The refusal is the house working correctly:
*it declines to guess where it is.*

So the smoke test now classifies that as a **skip, with the reason printed**, not a failure:

```
seated      26 called · 0 broken · 2 skipped
bare clone   6 called · 0 broken · 7 skipped   ← all "refuses to guess", all named
```

**A gate that reports an honest refusal as a failure is a gate people learn to ignore** — and then it
misses the next real one, which is the entire history of this week's gates in one sentence. Both
numbers are true; only one of them is a defect, and the output says which.
