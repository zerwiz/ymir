# 0.1.113 — the bin folder move, landed

`bin/` now HAS a shape. `bin/gates/checks/` holds four doors: `extension-api-check`,
`workflow-check`, `usage-ratchet`, `home-index-check`.

**The move itself had not landed**, which is why the Allfather saw a flat `bin/` after merging
#282: the rename commit was the one that conflicted (with #281, which had already removed the
stray file it was entangled with) and it was never re-applied. What DID land in #282 was the rule,
the root fix and the notes.

All four requirements the lesson demands, in ONE commit:

1. the doors moved (`git mv`, names unchanged)
2. every caller repointed — `ci-verify.sh`
3. **the enumerator made recursive** — `find bin ...` in BOTH the count and the row loop, because
   `ls bin/*.sh` drops a door the moment a folder exists (438 → 434, silently)
4. **the marker-walk applied to the moved doors**, so they can find their own repo from two levels
   down instead of resolving `ROOT` to `bin/gates`

Verified: **438 door rows, `capabilities --check` current**, inventory current, and the nine
`--fast` gates PASS including `usage`, `workflows` and `ext-api` — the three that went red the first
time this move was attempted.
