## `.agents/backend/` — every file examined, and the verdict was wrong

The shelf was reported as `provenance=163, tested=3, wired=2`. Measured file by file:

```
exercised by a test      162
called by a door          11
named only by docs         1
NOTHING references it      0      ← not one
```

**The cause was a name prefix that overrode every piece of evidence:**

```python
if name.startswith("fm-"):
    verdict = "provenance"     # ← it never asked
elif tested: ...
```

`bin/herdr-ensure.sh` *pins* `fm-install-herdr.sh` as its installer and `bin/hall-snapshot.sh`
*executes* `fm-procevent.sh` — and the shelf was filed as inert vendored reference kept
byte-comparable on purpose. Evidence now outranks the name, and `provenance` means what it says:

```
.agents/backend/   BEFORE  provenance=163  tested=3    wired=2     disposition keep=5
                   AFTER   tested=156      wired=12   provenance=0   disposition keep=168
```

**Every file in the shelf is accounted for, and not one is dead.** The one that is "named only by
docs" is a decision for a human, not a defect.

## Why this is the same bug as the others

| | |
|---|---|
| 0.1.95 | `deployed is not loadable` — counted files copied |
| 0.1.98 | `registered is not running` — counted tools declared |
| **0.1.99** | **`fm-` is not `inert`** — counted a name prefix |

Three gates, one shape: **a label decided by something cheap instead of by evidence.** The cheapest
thing available is always a name, a file count, or a declaration. The gate has to be built so that
being wrong is *loud* — and here it was quiet for the entire life of the shelf.

**Evidence first, provenance last.** `tested` wins, then `called by a door`, and only a file that
neither has can honestly be called provenance.
