# 0.1.111 — a door resolved the repo by counting `..`, and nesting blinded the register

> The attempted restructure of `bin/` rendered a capability register with **2 rows instead of 437**,
> and the gate called it clean. Reverted rather than ship a broken refactor.

## Cause — the thing that had to be fixed first

```bash
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"   # ONE level up
```

From `bin/gates/capabilities.sh` that is the repo. From `bin/gates/capabilities.sh` it is `bin/` — so the
generator searched for `bin/*.sh` **inside `bin/`**, found nothing, and reported an empty index.

> **A generator that resolves its own location by depth can be blinded by a folder.**
> Fix the resolver FIRST, move second. Anything else is a coin toss with a 437-row index.

## The fix, and it is why the restructure is now safe

Root is found by walking UP until the marker (`.pi/` + `RULES/`) appears, so **depth can no longer
blind it**. Verified: **438 rows**, `capabilities --check` current.

## And the law, so it does not need rediscovering

`RULES/12-bin-structure.md`:

1. Every door lives under a **system folder**; `bin/<system>/<verb>.sh`, never `bin/<verb>.sh` for
   anything new.
2. `bin/` root is an **ENGINE, not a drawer** — a short named allowlist, because if that list
   grows, the structure is failing.
3. A move **keeps name and behaviour**, and repoints every caller **in the same commit**.
4. **No door may resolve the repo by counting `..`.**
5. The register must **fail if its row count drops** without a recorded move — so the 437→2
   collapse can never again look like a clean run.

**A system folder with one file is not a system — keep them flat until a system genuinely has
sub-parts.** Depth for tidiness is the same mistake as a flat drawer, wearing better clothes.

Plan 70 carries the full shape, the method (one system per commit, gates green either side, the diff
**read** not asserted), and the traps. The grouping is a **proposal** — a wrong grouping teaches
people a false thing, which is worse than a flat drawer.
