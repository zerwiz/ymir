## gate · 0.1.60 · 2026-10-01 — the sweeper proposed a ledger that does not exist, and spoke two vocabularies

### Why
Found by **running the merged sweeper on the operator's real documents** rather than on its own
fixture — which is the whole point of a report-only tool. Two faults, both visible in the first
report:

1. **The PROPOSE destination was derived, and the derivation was wrong.** `bin/doc-sweep.sh` read
   the ymir project's realm from the registry (`work`) and built
   `svartalfaheim/work/projects/ymir/plans/` — **a realm with no ledger**. The canonical plan
   ledger lives under `whynotproductions`. The two are genuinely different things: the realm a
   project *works* in is not the realm its *ledger* is filed under, and the brief had said to read
   the registry — which the code did, and then drew the wrong conclusion from it. **A proposal
   pointing at a path that does not exist is worse than no proposal**, because it reads as a
   decision already made.
2. **The summary and the body spoke different vocabularies.** The summary printed
   `"unplaceable",64` while every one of those 64 lines printed `REPORT` in the body — so a reader
   could not tell whether the 64 were a different set from the 8. `set_class` mapped
   `move|propose` to verbs and **everything else** to `REPORT`, which made the summary's word a
   summary-only invention.

### Fix
- **The ledger is now DISCOVERED, not derived.** Exactly one existing
  `svartalfaheim/*/projects/ymir/plans` on this home wins; if several exist the report says so and
  asks for `--ledger`; only when **none** is found does it fall back to the registry — and it says
  `ledger_source: derived from the registry — no ledger found on disk` when it does.
- **The report names the ledger and how it chose it**, so the reader never has to guess:
  `ledger: …/svartalfaheim/whynotproductions/projects/ymir/plans` · `ledger_source: discovered`.
- **One vocabulary.** `unplaceable` is folded into `report` *before* the summary loop, so the key is
  printed once and the tally (which guards against under-reporting) still balances.
