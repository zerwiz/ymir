# The front doors stop counting — why two registers conflicted on every branch

**Date:** 2026-11-06 · **Component:** gate (`bin/gates/inventory.sh`, `bin/gates/capabilities.sh`, `.gitattributes`)

## What the Allfather said

> *"pull main and fix this files. we need to break them up so a sub system they are conflicting all the time. capabilities.md, .agents/assets/agents/capabilities.md, README.md, bin/README.md"*

## What was measured before changing anything

Plan 211 had already **split** both registers into 31 per-folder fragments
(`bin/<folder>/INDEX.md`, `.agents/assets/agents/capabilities/<folder>.md`) with a grown front
door — the right shape. Two things kept the collision alive anyway.

**1 · Main carried the residue of a half-merged register.** `origin/main`'s
`.agents/assets/agents/capabilities.md` held the fragment `gisters-are-a-tree` — half a branch
name, left where a conflict was resolved by hand — and its `bin/README.md` held **844 stale per-door
rows** under the new front-door text: the old table and the new map in one file. `bin/gates/registers.sh
check` said both **STALE** on main. Every branch that regenerated them then collided with the corpse.

**2 · Both front doors printed a count that changes when ANY door is added.**
`bin/README.md` printed `folders[]{folder,files,what,index}` — a per-folder file count — and
`capabilities.md` printed `capabilities[5]{surface,count}` (with a **date stamp**) plus
`capability_folders[]{folder,doors,index}`. So adding one door in `bin/forge/` rewrote **both** files,
on every branch, and any two branches collided — inside the very split that exists to prevent that.
A date stamp made it worse: two branches cut either side of midnight conflicted over nothing.

## What changed

| where | was | now |
|---|---|---|
| `bin/README.md` front door | `folders[]{folder,files,what,index}` + "N indexes over M files" | `folders[]{folder,what,index}` — no count, no total |
| `capabilities.md` front door | `capabilities[5]{surface,count}` + a date stamp | `surfaces[4]{surface,where}` — no count, no date |
| `capabilities.md` front door | `capability_folders[]{folder,doors,index}` | `capability_folders[]{folder,index}` |
| `.gitattributes` | fragments took a plain text merge | `bin/INDEX.md`, `bin/*/INDEX.md`, `capabilities/*.md` are `merge=regenerate` |

Counts did not disappear — they moved to where the rows are: each `bin/<folder>/INDEX.md` keeps its
**tally**, and each capability fragment keeps its own rows. A page that lists folders changes when a
**folder** appears; it no longer changes when a door does.

## Proved

**The front doors are now invariant under a door being added** — a probe door was staged in
`bin/forge/`, the registers regenerated, and both front doors were byte-identical:

```
the front page UNMOVED by an added door ✓
the capability index UNMOVED by an added door ✓
```

**And the generators are idempotent** — two runs in a row produce the same bytes:

```
bin/README.md stable ✓
capabilities.md stable ✓
```

**The repair itself:** `bin/gates/registers.sh generate` on current main rewrote 12 files,
**−1593 lines**, and `check` went from `STALE, STALE` to `current, current`. The residue line is gone.

The wards agree: `inventory-guard`, `registers-guard`, `weave-guard`, `features-guard`,
`language-guard`, `defaults-guard`, `rules-compliance-guard`, `docs-claims-guard` — all PASS.

## What this does not fix

- **A conflict inside one folder** is still a conflict: two hands adding a door to `bin/forge/` both
  rewrite `bin/forge/INDEX.md`. It is now small (one folder), it is regenerated by the merge driver
  rather than resolved by hand, and it is the irreducible minimum of a derived file.
- **`.agents/backend/README.md`** is still one flat table. His word named the two files above; the
  backend index is the same shape and the same fix applies when it next collides.

## Files

- `bin/gates/inventory.sh` — the front door lists folders, never counts
- `bin/gates/capabilities.sh` — `surfaces[]` instead of counts and a date; `capability_folders[]{folder,index}`
- `.gitattributes` — the per-folder registers and fragments are `merge=regenerate`
- `bin/README.md`, `bin/*/INDEX.md`, `.agents/assets/agents/capabilities.md`, `…/capabilities/*.md` — regenerated
