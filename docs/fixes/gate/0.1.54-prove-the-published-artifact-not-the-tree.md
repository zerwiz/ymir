## gate · 0.1.54 · 2026-09-29 — prove the PUBLISHED artifact, not the tree

### Why
The compliance gate passed on `main` and **the published tarball still failed four of its own
wards** — verified by installing `@zerwiz/ymir@0.1.53` into a clean directory and running the
gate there:

| Ward | Why it failed in the artifact |
|---|---|
| `governed` | `config/` was **never in the `files` list**, so `config/cron.yaml*` (a governed path) did not exist in the tarball at all |
| `skillindex` | a shipped skill cited `.agents/skills/smidja-factory` — a **symlink** to a clone of another repo, which npm cannot carry |
| `harnesses` | `.claude/skills`, `.codex/skills`, `.cursor/skills` — **symlinks** to `.agents/skills` (Rule 02), absent for the same reason |
| `sync` | `.agents/skills/tyr-check/assets` is a **symlink** to the canonical assets, so the mirror could not be compared |

**npm does not pack a symlink as a symlink.** Three of the four are therefore not oversights
but a structural property of the package, and the `files` list is a *silent second source of
truth*: every in-repo test runs in the full tree, where those paths all exist, so nothing could
see it. The list was byte-identical across 0.1.51 and 0.1.53 — this shipped for many releases.

### Fix
- **`bin/packaged-gate.sh`** — a new gate: `npm pack` → unpack to a temp dir → run the
  compliance gate **inside the artifact**, which is the only place the drift is visible. An
  **undeclared** missing path is a FAIL; a **declared** seam is not. It also asserts that the
  seam manifest itself shipped — an absent seam must never be indistinguishable from a broken one.
- **`packaging/symlink-seams.json`** — the artifact now **declares** what it cannot carry, each
  entry naming the path, its kind, and **the door that seats it on a real machine**
  (`bin/seat/valknut-load.sh --all`, `bin/ymir-install.sh`'s apps step). A machine gets the symlink
  from the installer; the tarball must not ship a copy that could drift from the canonical one.
- **`package.json`** — `config/` added to `files`, so the governed path and the shipped
  templates/schemas are actually in the package.
- **The `sync` ward** reads the seam manifest: when the judge's mirror is a declared seam and
  is absent, it reports `SKIP` with the reason instead of a phantom `FAIL` ("drift detected").
  An undeclared absence still fails.
