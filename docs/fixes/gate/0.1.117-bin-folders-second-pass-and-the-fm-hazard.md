## THE HAZARD — the vendored `fm-*` files are NOT safe to move

`bin/backend/fm-session-start.sh` writes `state/.session-start-complete` **relative to `$0`**.
Moving it from `bin/` to `bin/backend/` silently moved its state directory to `bin/state/`, which
`runtime-guard` caught as *undeclared runtime output* — and I removed by hand.

> **A file kept "byte-comparable to upstream" is byte-comparable; it is NOT location-independent.**
> 156 files that resolve paths from `$0` were moved in one pass, and that is a change of
> **behaviour**, not of location.

**This is the strongest argument for reverting `bin/backend/`** — leave the vendored shelf where it
was, or give each of its files an explicit state root before moving it again.
