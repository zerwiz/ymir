## gate · 0.1.54 · 2026-09-29 — the judge was right: an unrunnable gate went red, and zod was never declared

### Why
Forseti judged PR #251 (`managandr: the read calendar`) **NEEDS-REWORK, 2 items**. Both
were correct, and the first is the same fault class this repo mended hours earlier for
`contracts-check.sh` — recorded here so the pattern is visible twice.

1. **An unrunnable gate reported red.** `.agents/tests/managandr-reader.test.sh` imported
   the reader, which imports **`zod`** — and on a checkout with no `npm install` the suite
   died with `ERR_MODULE_NOT_FOUND: Cannot find package 'zod'`, i.e. it reported a fault in
   correct code on a machine that simply had not installed. The repo's own rule, written
   2026-09-30 into `contracts-check.sh`: *a gate that cannot run must say so, never fail the
   push*. That rule now reads `skip … run npm install` and exits 0.
2. **`zod` was declared nowhere.** Not in the root `package.json`, not in any app or tool
   manifest — it reached `node_modules` only transitively, through an eslint plugin. A shipped
   runtime that imports a package nobody declares is one `npm ci` away from breaking.

The judge's second item was a one-character truth: `usage()` printed `sed -n '2,27p'` while
the header block ends at line **28**, so `bin/calendar-ask.sh -h` cut its last sentence in
half ("`probe` prints none unless `--titles` is asked" — no "for").

### Fix
- The suite now probes for its dependency first and **skips loudly** with the remedy, exiting 0.
- `zod` declared in the root `package.json` dependencies, with `package-lock.json` regenerated
  (`npm install --package-lock-only`) so `npm ci` resolves it.
- `bin/calendar-ask.sh` usage block → `2,28p`.

### Verified
- **The judge's own reproduction, re-run:** a fresh clone with **no `node_modules`** now prints
  `skip - dependencies absent — run npm install to exercise the reader` and exits **0**. It
  reported red before this change.
- With dependencies present the suite still runs **every** check: `all checks passed` (16/16).
  The skip did not silence anything.
- `bash bin/calendar-ask.sh -h` now ends with the whole sentence.
- The lock carries `zod` at the root and `node_modules/zod` resolved.

### Standing
- The Allfather sealed #251 anyway (his word is the seal). These two items are the debt that
  seal left, and they are paid here rather than reopened.
