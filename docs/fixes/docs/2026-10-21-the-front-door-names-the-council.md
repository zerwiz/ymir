## docs · 2026-10-21 — the front door names the council

### Why
The README described the crew, the assistant and the ear, and never mentioned the thing the
Allfather asked for by name twice in one night: a council of minds that argues a question and hands
down one verdict. Its chair, its modes and its memory lived only in plan 92 and in the room
records.

### Fix
A section, **The council — several minds, one verdict**: seats carry lenses rather than votes; the
same model in five chairs is still worth doing (five lenses on one mind find more than one mind
with no lens); the chair is Móðguðr, the bridge-keeper, whose laws are written in her own voice and
who never edits because a chair that repairs what it audits has no verdict; the four modes
(`divide` · `sortie` · `report` · `debate`); and the two things that make a sitting count — the
chair drinks the well before and waters it after, and every word lands in the rooms, attributed,
because an argument that lives only inside five model contexts never happened.

It closes with the boundary: a council writes no code, merges nothing and pushes nothing. A verdict
is a record; the build is a separate errand, and the chain stays in the Allfather's hand.
