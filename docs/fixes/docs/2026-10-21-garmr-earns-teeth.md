## docs · 2026-10-21 — Garmr earns teeth, in writing

### Why
The Allfather asked the question the guardian plan had left open: *"he needs to bite back for hacker
attacks. Don't we bite back on non-approved happenings?"* The honest answer was **partly**: the gates
already refuse at their doors (a protected branch, a secret, a vault copy), but detection had no
teeth — the hound could see a new listener, an unknown program from a writable path, or egress to a
host nobody named, and all he could do was bark while the door stood open.

### Fix — in plan 98 (the guardian), and mirrored on the front door
A **bite allowlist**: close a listener nobody named · stop a unit that started behaving oddly · kill
a process that has no unit and came from a writable path · block egress to a non-peer · quarantine a
file that ran without being in the manifest · revoke a token that appeared with no approval record.
Nothing else, ever.

Four laws make it safe to run: **no bite without a rule** (an unmatched finding is a bark); **recorded
before the act**, with the un-bite command inside the rune; **never the operator's own hands** (not
his terminal, not an open vault, not a model mid-generation); **every bite announced at CRITICAL**
with its reversal in the message.

And the boundary the word "bite back" invites, stated so it cannot drift: **nothing leaves the
machine**. A blocked destination is a door we closed, not a counter-strike; no counter-scan, no
retaliation. The switch (`off · report · contain · hard`) is the Allfather's and ships at `report`,
and the first week of real containment is one class only — the egress block — because an active
defender can brick its own house.
