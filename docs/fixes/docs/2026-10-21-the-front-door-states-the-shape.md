## docs · 2026-10-21 — the front door states the shape

### Why
The Allfather asked the sharpest question a project can be asked: *"are Ymir so lean anymore?"*
The README answered with one sentence and a chain, and neither said what the machine actually is:
one operator, one repository, adopted engines under Norse names, a primary agent in the hall, a
crew that forges in isolation, a council with a chair that cannot be flattered, and a record of
every word.

### Fix
The opening paragraph became a short statement of shape, in four movements:

- **what it is** — one operator, one repo, no tenancy machinery, a crew that returns with an
  artefact or says plainly it could not;
- **what is in it** — adopted engines (worktrees, sandboxes, an embedding store, a chained
  ledger) under names that explain the job; Brokk, the Eindri, the council, Skírnir, and the
  rooms where they argue in the open;
- **what it refuses** — private data never in the tree, every change by pull request, no mock in
  the shipped path;
- **what it is not** — not a platform, not a framework, not a chat window with tools bolted on.

### The honest measure it does NOT claim
Lean is a claim about *surface*, and Ymir's surface is not small: 413 shell doors, 525 files in
`bin/`, 22 figures, 22 extensions, 29 skills, 24 guards, 49,028 tracked lines. What is lean is
the **shape** — one operator, one chain, adopted engines — not the surface. The next honest pass
is a cull driven by the maps that already exist (`usage`, the capability register, the doc
grader), not another feature. That is written here so the claim in the README is read as it is
meant.
