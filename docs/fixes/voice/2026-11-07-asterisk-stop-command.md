# Voice stop command uses `**`

**Date:** 2026-11-07

The voice (TTS) stop command is `**` (two asterisks). Speaking or typing `**` stops the voice output. This was discovered during a session and is not documented in any how-to page or feature row. The feature row "Voice notes — speaking to Ymir and hearing it answer" does not mention the stop command.

**Action needed:** Add the stop command to the voice how-to page and the feature row.
