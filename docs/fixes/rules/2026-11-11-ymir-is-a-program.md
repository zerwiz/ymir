# Ymir is a program, and it runs globally (RULES/51)

**Date:** 2026-11-11 · **Component:** rules

The house had built the pieces — root installs per harness (plans 161, 169), the extension → MCP collapse (183), the pinned runtime (RULES/02 §7) — but no law said what they were for, so features kept being proved from inside the checkout and root agents kept loading a working tree (PR #654). A dated section in `AGENTS.md` carries it; the build is plan 248 in the home ledger.
