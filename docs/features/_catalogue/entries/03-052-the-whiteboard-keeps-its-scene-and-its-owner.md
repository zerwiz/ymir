| Whiteboard | **A whiteboard that keeps its board** (`systems/whiteboard/`) | The room server writes each room's encrypted scene to disk on a cadence, on the last client leaving and on stop — one file per save, append-only, so a board opens again tomorrow. A saved board belongs to the identity the gate asserts (`Remote-User`), never to a value the browser sends: you list your own, and another person's save is refused **by name** rather than answered with an empty list. The assistant gained a `converse` mode beside `generate` — talking first, at most two questions, then drawing — with seven tools that are all the whiteboard's own and no reach for the hall, the ledger, mail or the web; `generate` still returns bare Mermaid.
