| Federation | **The constellation road** (`bin/bridge/constellation.sh` · `constellation-tool.mjs` · `constellation-grants.py` · `bin/gates/guards/constellation-grant-guard.sh`) | Two independent Ymir fleets can exchange one question and one answer without sharing a login, a database or a fleet. Each house publishes a **card** (name · endpoint · skills · public key, validated against the one shared agent-card contract), writes a **grant** in its own hoard naming the peer's skills and an expiry, and signs a short-lived **EdDSA token** for one named skill that the receiver verifies against the public key already on the sender's card. `list` · `show` · `grant` · `countersign` · `activate` · `mint` · `verify` · `revoke` · `guard` are the verbs; a grant is `pending` until both houses sign, a token cannot be minted for a skill no active grant names, a grant cannot name a skill the peer's card does not declare, and a card carrying a secret is refused. Corrects the assumption that Gimlé's MCP connects fleets: MCP is a tool face *inside* a house, this road is between houses | [The constellation road](docs/features/constellation-the-road-between-fleets.md) |
