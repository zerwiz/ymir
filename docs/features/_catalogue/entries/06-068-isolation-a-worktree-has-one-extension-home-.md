| Isolation | **A worktree has one extension home** (`bin/forge/yggdrasil.sh create` · `bin/seat/valknut-load.sh --check|--ext-home` · `.agents/tests/pi-extensions.test.sh` §8) | Corrects the Isolation row above: a worktree used to check `.pi/extensions/` out like any other file, so a pi seat inside it loaded the same eighteen extensions twice — two absolute paths, two registrations, every tool name colliding, pi exiting, and the dispatcher typing the brief into the bare shell left behind (four errands died that way on 2026-10-24). `create` now excludes that one path by a per-worktree sparse-checkout (`/*`, `!/.pi/extensions/`) — files stay tracked, the worktree stays clean, nothing existing is rewritten, and a symlink is refused because it shows as deleted tracked files. The gate learned the case it could not name: a worktree of the **seated** repository is ONE home (`state: shared`, served by the seat tree), a worktree carrying its own copy is the fault (`state: shared-copy`, FAIL with the one-line repair printed), and "same repository" is asked of git's `--git-common-dir`, never inferred from a path. `--ext-home` prints which tree serves the tree you stand in, so a human, the gate and the test ask one door. Measured in a fresh worktree: `.pi/extensions` absent, status clean, `--check` PASS, and `pi --list-models` exit 0 with 496 models and no collisions | [docs/features/yggdrasil-and-utgard-isolation.md](docs/features/yggdrasil-and-utgard-isolation.md) |
