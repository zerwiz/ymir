| Mail | **The import window — a high-water mark, and a gap that speaks** (`bin/mail/gna_import.py` · `bin/time/nornir-job-gna-mail.sh` · [how-to](docs/features/gna-the-one-mail-desk.md)) | The clock used to ask the mailbox for *the last N days*, measured from **now** — so every hour the desk was down was an hour it never asked about, and a run after a week of downtime read two days and looked exactly like a quiet inbox. Now each account keeps a **high-water mark**: the newest message read and the moment the desk last looked (`state/gna-mail-watermark.json`), and the ask is everything since it — `after:<epoch>` on Gmail, `SINCE <the mark's day>` on IMAP, paginated because Gmail answers newest-first and a single page would keep the newest hundred and drop the oldest of the outage. The mark only moves forward, is read from one second before itself so a same-second arrival is not lost, and `--days` survives as an override for a backfill. **And the gap is named**: before reading, the run measures the silence from the last run that ended well (a failed run is not a look), prints `GAP the desk was blind for N days — from … to …` when it exceeds `GNA_RUN_INTERVAL_HOURS` (default 24), records the same measurement under `gap` in `state/gna-mail-last-run.json`, and the next notice opens with that sentence once. Proved by `bin/mail/tests/test_gna.py`'s `ImportWindow`: a week of downtime against a stub transport, proving every message in the gap is stored, that the query says `after:` and never `newer_than:`, and that the gap reaches the record and the notice's first line | [docs/features/gna-the-one-mail-desk.md](docs/features/gna-the-one-mail-desk.md) |
