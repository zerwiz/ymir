| Collaboration | **The work road — an ask to a merged change** (`ymir work`, `bin/fleet/work.sh`, `ymir release npm`) | One path for work: `ymir work send` makes a labelled issue, intake queues it, a worker builds it in a worktree, a judge from another model family reads it, and a merge tier decides whether it merges by itself (documents), only if switched on (code), or waits for you (rules, config, releases). You choose two things: the mode (solo, fleet, offline) and the model per role (free models by default). Research goes through Huginn and kept answers are reused.
