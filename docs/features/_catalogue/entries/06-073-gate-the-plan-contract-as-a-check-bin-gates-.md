| Gate | **The plan contract, as a check** (`bin/gates/plan-audit.sh`) | Audits the plan ledger against the seven-item contract in one command: his words quoted and dated · a measured section · phases that each end in something observable · what it refuses · the questions that are genuinely his · a number used once · an index row carrying a status. It reads the **outline**, not the spelling — a phase is a `Phase N` heading, a `phases[]` block, the items of a `## Phases` section, or numbered sections `## N ·` — because counting the word "Phase" is how the audit that commissioned it lied about the shelf (16%, where the honest measure is 60%). `--rows` emits the missing README rows from each plan's own opening; `--check` exits nonzero on a gap and is wired into `ci-verify`; a shelf that is absent (CI has no vault) SKIPs loudly at exit 0. Read-only: it never renumbers a plan or rewrites a row | [docs/features/the-plan-ledger-and-runes.md](docs/features/the-plan-ledger-and-runes.md) |
