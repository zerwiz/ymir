# `.pi/` — the repository's root mark

The gates in `bin/gates/guards/` are Ymir's own, copied byte for byte (see `VENDORED`). They find the root of the
repository they judge by walking up until they see a `.pi/` folder beside a `RULES/` folder, as Ymir's tree has.

This folder is that mark, seated by Ymir's gate pack. Do not remove it: without it the secret, identity and vault
guards judge the wrong folder and fail. It may also hold a coding agent's settings for this repository.
