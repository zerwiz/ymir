# areas/ — what this project answers for

One file per area, from the canon of eighteen. Each says who holds it, what they may write,
and the evidence that closes it. `bash scripts/areas.sh check` names what is unanswered;
`scripts/gates/areas-guard.sh` refuses a change to an area nobody holds.

A waiver names who waived it and until when. An empty answer is honest; a silent one is not.
